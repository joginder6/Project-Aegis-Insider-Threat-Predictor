# Insider Threat Intelligence System
**Final Year Minor Project**  
*Diploma in Computer Science Engineering*

A hybrid Machine Learning pipeline that predicts corporate security risks. It fuses human psychometric indicators with system telemetry logs to detect insider threats before they happen.

## Features
- **Data Pipeline & Training:** Full data processing, feature engineering, and model training (AdaBoost/XGBoost) documented in the Jupyter Notebook.
- **Interactive Dashboard:** A functional Streamlit interface for real-time risk scoring and prediction.

*Note: Raw datasets (.csv) and trained model weights (.pkl) are omitted via .gitignore due to size and privacy.*
